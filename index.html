01
DAY ONE · 16 OCT

Set Up.
Take Control.

Set up your coding environment, get comfortable with the terminal, and learn how Git tracks your work and GitHub helps you share it. Your first step into the world of development starts here.

VS Code Terminal Git GitHub
✦
02
DAY TWO · 17 OCT

Structure.
Style. Create.

Go beyond the basics with HTML and CSS. Structure webpages, experiment with layouts, explore styling, and turn your ideas into designs you can actually see in your browser.

HTML Advanced HTML CSS Layouts
